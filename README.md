# COVID_Xray_CNN

A deep learning-based medical image classification project that detects **COVID-19** from chest X-ray images using Convolutional Neural Networks (CNN). The model is trained to classify X-ray scans, demonstrating how artificial intelligence can assist healthcare professionals in the early screening and diagnosis process.

> Built using Python, TensorFlow/Keras, and OpenCV to explore the application of deep learning in medical image analysis.

---

## Features

### Deep Learning Model
- CNN-based image classification
- Automated feature extraction from X-ray images
- Binary classification for COVID-19 detection
- Optimized training using TensorFlow/Keras

### Image Processing
- Image resizing and normalization
- Data preprocessing pipeline
- Dataset preparation for model training
- Support for grayscale chest X-ray images

### Model Evaluation
- Training and validation accuracy
- Loss visualization
- Performance evaluation on unseen data
- Prediction on test X-ray images
